Unified Casper CEP client library (CEP-18, CEP-78, CEP-85, CEP-95).

Builds on [casper_rust_wasm_sdk]. CEP-specific enums, dictionary-key helpers, and contract error maps live here; RPC, transactions, and wait helpers stay in the SDK.
